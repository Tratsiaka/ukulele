# sources-en

## summary
Живые проверки шли с этой машины (сеть в США, Cloudflare-узел EWR), это не сеть владельца. Из того, что реально работает, сильнейший международный источник аккордов — Ultimate Guitar. Страницы табов и поиска отдают 200, а JSON в `div.js-store[data-content]` содержит текст с разметкой `[ch]Am[/ch]`/`[tab]…[/tab]`, тональность, каподастр, строй (у типа «Ukulele Chords» это G C E A), бой (strummings с bpm) и аппликатуры для укулеле. Фильтр `type=800` находит укулельные версии, в том числе русские песни (по «Группа крови» 57 результатов). Второй по надёжности — ukulele-tabs.com (`pre a.chord`). Третий — chordie.com: он отдаёт готовый ChordPro в `textarea#chordproContent`, но с обрезанной лирикой (только первые слова строки и «...»), поэтому годится как скелет аккордов. Для испанского подходит lacuerda.net (`#t_body pre A`). Автоматически недоступны: e-chords (403, Cloudflare WAF), ukutabs (403, своя защита от VPN и хостингов), ozbcoz, Chordify и Genius (403, Cloudflare challenge), Cifra Club (403, Akamai). Songsterr на второй запрос вернул ERR_ACCESS_POLICY с прямым запретом скрейпинга. Ни у одного HTML-источника нет заголовка Access-Control-Allow-Origin, поэтому импорт идёт только через серверный адаптер на уже существующем Vercel-relay с кешем в Neon. Кроме того, нужен универсальный импорт «вставь текст или поделись ссылкой» (Web Share Target): он работает для любых, в том числе заблокированных, сайтов. Лучший запасной источник лирики — LRCLIB: открытый, CORS `*`, без ключа, есть synced LRC и русские песни. Его ограничения: качество неровное (у «Кино» встречались английские переводы), а `/api/search` весит около 217 КБ, поэтому лучше `/api/get` с duration или `/api/v2/search`. Лучшее API для метаданных и превью — iTunes Search: CORS `*`, 30-секундный `previewUrl` (m4a тоже с ACAO `*`), обложки, работают `country=ru` и `country=by`. Deezer полезен как источник BPM (`/track/{id}.bpm`), но его JSON без ACAO (нужны JSONP или relay), а ссылки на превью подписаны и истекают. Датасеты (Chordonomicon CC BY-NC 4.0, ChoCo CC BY 4.0, McGill Billboard CC0) не содержат лирики. Chordonomicon (666 тыс. прогрессий по секциям) годится только для офлайн-подбора песен под набор лёгких аккордов, и названий в нём нет (есть только Spotify ID). Для РФ важный фактор — замедление Cloudflare до 16 КБ на ответ у российских провайдеров (с 09.06.2025). Оно бьёт по lrclib.net, ultimate-guitar.com и ukulele-tabs.com при прямых запросах с клиента; действует ли оно сейчас и есть ли что-то подобное в РБ, я не проверял.

## recommendations
- [must] Импорт только через адаптеры на Vercel-relay, кеш в Neon: Ни у одного HTML-источника нет ACAO (проверено: UG, ukulele-tabs, chordie, lacuerda, doctoruke), поэтому fetch из PWA невозможен. Схема: PWA → `https://<relay>.vercel.app/api/songs/{search|fetch}?src=ug&url=…` → адаптер (search → fetch → parse) → нормализованный ChordPro + `{source, sourceUrl, fetchedAt, key, capo, tuning, bpm, strum}` → таблица songs в Neon. Повторный запрос берётся из кеша, запросы к источнику только по действию пользователя (не краулер), не чаще 1 в 2–5 секунд на домен (у lacuerda Crawl-delay 5, у e-chords 10). Relay заодно снимает проблему российского замедления Cloudflare (16 КБ) и 403 от Neon. Импортированные песни НЕЛЬЗЯ класть в docs/ на публичном GitHub Pages: лирика защищена авторским правом, хранить только в приватной БД.
- [must] Адаптер №1: Ultimate Guitar (страницы табов): Fetch: `https://tabs.ultimate-guitar.com/tab/<artist>/<song>-(ukulele|chords)-<id>`. Parse: `div.js-store` → `html.unescape(data-content)` → JSON → `store.page.data.tab_view.wiki_tab.content`. Аккорды размечены `[ch]X[/ch]`, пары строк «аккорды над текстом» обёрнуты в `[tab]…[/tab]`, секции `[Verse 1]`, переводы строк `\r\n`. Метаданные: `tab_view.meta{capo,tonality,tuning.value,difficulty}`, `tab_view.strummings[{part,bpm,denuminator,measures[{measure}]}]`, `tab_view.applicature{Am:[{frets,fingers}]}`, `tab{song_name,artist_name,type,rating,votes}`. Конвертация: убрать `[ch]`/`[tab]`, затем ChordsOverWords → ChordPro. Поиск: `https://www.ultimate-guitar.com/search.php?search_type=title&value=<q>&type=800` (укулеле; 300 = Chords) → `store.page.data.results[]`. Брать только `tab_access_type==='public'`, отбрасывать `marketing_type` official/TabPro. Учесть, что robots.txt запрещает /search.php: поиск только по явному действию пользователя, либо получать URL через вставку.
- [must] Адаптер №2: ukulele-tabs.com: Поиск: `https://www.ukulele-tabs.com/search-uke-chords.html?find=<q>` → в `#content` ссылки `a[href*='-uke-tab-']`. Шаблон песни: `/uke-songs/<artist-slug>/<song-slug>-uke-tab-<id>.html`, страница артиста `/uke-songs/<Artist+Name>-uke-tabs.html`. Parse: единственный `pre` (style color:#454545), аккорды в `a.chord` (class `ut_crd_tooltip ukechord_tooltip chord`; textContent — имя аккорда, img внутри без текста), строки разделены `<br>`. Конвертировать innerText → ChordsOverWords → ChordPro. Сайт изначально укулельный, но русских песен почти нет (по запросу «кино» результатов не нашлось).
- [must] Универсальный импорт «вставить текст / поделиться ссылкой»: Web Share Target в manifest.json (`share_target` с action `/import`, `params.url`/`text`) плюс textarea для вставки. Парсер ChordSheetJS (npm `chordsheetjs@18.0.0`, GPL-2.0-only; есть ChordProParser, ChordsOverWordsParser, UltimateGuitarParser, транспонирование), для разбора и транспонирования имён аккордов — `chord-symbol@4.0.0` (MIT). Так покрываются заблокированные источники: e-chords, ukutabs, Cifra Club, ozbcoz, Genius. Это и самый честный по ToS путь: пользователь сам открыл страницу.
- [must] Запасной источник лирики: LRCLIB: `GET https://lrclib.net/api/get?artist_name=&track_name=&album_name=&duration=` (длительность ±2 с; брать из iTunes trackTimeMillis/1000) → `{id,trackName,artistName,albumName,duration,instrumental,plainLyrics,syncedLyrics,lyricsfile,hasWordSync}`. Поиск: `/api/v2/search` (beta, без текста), затем `/api/get/{id}`. Старый `/api/search` отдаёт ~217 КБ на 20 записей — не использовать. CORS `*`, ключ не нужен. Заголовок `Lrclib-Client: UkeApp/0.1 (+url)` поднимает лимит с ~45 до ~90 запросов/мин; `Lrclib-App-Id` (бесплатная регистрация) даёт ~180/мин. Соблюдать `Retry-After` на 429. synced LRC пригодится для караоке-подсветки. Для РФ ходить через relay. Обязателен ручной выбор версии: у «Кино — Группа крови» попались записи с английским переводом.
- [should] Метаданные и превью: iTunes Search API, Deezer для BPM: iTunes: `https://itunes.apple.com/search?term=<q>&entity=song&limit=5&country=ru|by|us` и `/lookup?id=`. CORS `*`, content-type text/javascript (парсить как JSON). Поля trackId, artistName, trackName, collectionName, previewUrl (m4a ~1 МБ, ACAO `*`, accept-ranges), artworkUrl100 (подстановкой `100x100bb`→`600x600bb`), trackTimeMillis, primaryGenreName, releaseDate. Лимит около 20 запросов/мин (по документации Apple, сам не проверял). Deezer: `https://api.deezer.com/search?q=artist:".." track:".."` и `/track/{id}` (bpm, например 103.1 у Riptide; gain; isrc; available_countries включает RU и BY). JSON без ACAO: использовать `&output=jsonp&callback=` или relay. preview mp3 подписан (`hdnea=exp=`), URL не кешировать.
- [should] Адаптер №3: chordie.com как скелет аккордов: Поиск `https://www.chordie.com/results.php?q=<q>` → `a[href^='/chord.pere/']`. На странице песни готовый ChordPro: `textarea#chordproContent` (name=`chopro`, есть `{t:}`/`{st:}`), в HTML — `div#song .chordline span.absc`. Лирика обрезана до первых слов строки и «...»: годится для прогрессии и структуры, полный текст брать из LRCLIB или вставки. robots.txt разрешает всё, кроме /editsong.php и /admin/. Cloudflare нет (nginx/1.4.6). Сам контент — агрегация guitartabs.cc, guitaretab.com, azchords.com.
- [could] Испаноязычный адаптер: lacuerda.net: Шаблон: `https://acordes.lacuerda.net/<artist>/<song>.shtml` (200, без Cloudflare), разметка `#t_body pre`, аккорды `<A>G</A>`. Поиск: `https://acordes.lacuerda.net/busca.php?exp=<q>`. robots.txt: `Crawl-delay: 5`.
- [could] Подбор песен под выученные аккорды: Richard G, Bytown, Doctor Uke, Chordonomicon: Richard G (`https://scorpexuke.com/songs/`, 1381 песня): у каждой `[itemprop=musicalKey]` и «/N» — число аккордов, PDF по `https://scorpexuke.com/allpdfs/<Title_Artist>.pdf`; это готовый фильтр «≤4 аккорда» с переходом в PDF. Bytown: теги `/tag/05chord/`, листы песен — PDF в Nextcloud. Doctor Uke: 3919 аранжировок (PDF и MP3, у баритона вариант `<slug>bar.pdf`), только с educational-оговоркой. Chordonomicon (CC BY-NC 4.0, 264 МБ CSV) обрабатывать офлайн в build.py: считать, какие песни играются набором C, Am, F, G. Но названий в датасете нет, только spotify_song_id, их придётся резолвить отдельно.
- [could] Hooktheory: «песни с этой прогрессией»: `GET https://api.hooktheory.com/v1/trends/songs?cp=1,5,6,4` → `[{artist,song,section,url}]`, 20 на страницу. Авторизация: `POST /v1/users/auth` (логин и пароль Hooktheory) → `activkey` как Bearer, живёт около часа. Лимит 10 запросов за 10 секунд. Без токена проверено 401, ACAO `*`. Лирики нет; только для обучающих подборок, вызывать через relay, чтобы не держать учётку в клиенте.
- [avoid] Не автоматизировать: Songsterr, мобильный API UG, ukutabs, Chordify, e-chords, Cifra Club, ozbcoz, Genius: Songsterr: ERR_ACCESS_POLICY и прямой запрет, robots `Disallow: /api/`. Мобильный API UG: 406 без подписанных заголовков, это обратная разработка (ToS 6.4). UkuTabs: собственная блокировка VPN, хостингов и «автоматических» визитов. Chordify: Cloudflare challenge, публичного API нет. e-chords: Cloudflare WAF, robots запрещает /search и /api/. Cifra Club: 403 от Akamai. ozbcoz: Cloudflare challenge. Genius: API без лирики, страницы закрыты challenge. Для всех — только переход по ссылке и импорт вставкой.
- [avoid] lyrics.ovh не использовать как основной источник: Отвечает 200 с ACAO `*`, но русских песен нет (404 «No lyrics found» через 5,6 с), сервис неофициальный (Express за Caddy), синхронизированной лирики нет. Максимум — третий запасной вариант для английских песен.

## risks
- Анти-бот защита на IP датацентров: с этой машины уже получают 403 e-chords, ukutabs, ozbcoz, Chordify, Genius (Cloudflare) и Cifra Club (Akamai). Vercel-функции тоже ходят с IP датацентров (AWS), поэтому UG и ukulele-tabs могут начать выдавать challenge — нужен fallback на импорт вставкой.
- Российские провайдеры (Ростелеком, МТС, Мегафон, Билайн) с 09.06.2025 режут ответы Cloudflare до первых 16 КБ (подтверждено Cloudflare). Страницы UG весят 130–160 КБ, ответ /api/search LRCLIB ~217 КБ, страница ukulele-tabs ~235 КБ, так что при прямых запросах из РФ они не загрузятся. Ходить через vercel.app relay. Действует ли ограничение в ноябре 2026 и есть ли что-то подобное в РБ, я не проверил.
- Юридически: лирика и табы защищены авторским правом. UG ToS 6.3 — только personal non-commercial, robots.txt UG запрещает /search.php. Публичный репозиторий GitHub Pages (docs/) не должен содержать импортированные песни, только приватная БД Neon и личное использование.
- Хрупкость разметки: структура `store.page.data.tab_view.wiki_tab.content` в UG и классы `ut_crd_tooltip` на ukulele-tabs могут поменяться. Нужны фикстуры HTML и тесты адаптеров, а при сбое — переход к импорту вставкой.
- Качество LRCLIB неровное: для «Кино — Группа крови» часть записей содержит английский перевод, synced есть не у всех. Без duration и ручного выбора версии будут ошибки.
- У chordie лирика обрезана до первых слов строки. Склеивать её с полным текстом из LRCLIB автоматически ненадёжно: аккорды привязаны к позициям в обрезанной строке.
- Deezer: в JSON нет ACAO, ставятся куки Akamai Bot Manager, preview-URL истекают, сервис ушёл из РФ в 2022, регистрация новых приложений приостановлена с 2025. Опираться на него как на основной источник рискованно.
- Chordonomicon не содержит названий (только spotify_song_id), а Spotify Web API недоступен из РФ/РБ и требует регистрации приложения. Резолвить ID в названия придётся офлайн, из другой сети, или через URL-связи MusicBrainz (покрытие частичное).
- PDF-источники (Doctor Uke, Richard G, Bytown) без отдельного парсера позиций pdf.js не превращаются в ChordPro. Doctor Uke — не public domain, а «for educational purposes only».
- Все проверки шли из сети в США. Коды ответов из сети владельца (РБ/РФ, возможно через VPN) могут отличаться, особенно у ukutabs (блокирует VPN) и archive.org (Cover Art Archive).

## open_questions
- Владелец в Беларуси или в России, пользуется ли VPN? От этого зависит, ходит ли клиент в LRCLIB и iTunes напрямую или всё идёт через relay (замедление Cloudflare в РФ, блок VPN у ukutabs).
- Пропускает ли Cloudflare Ultimate Guitar запросы с IP Vercel-функции (iad1/fra1)? Нужна живая проверка из задеплоенного relay до того, как делать UG основным адаптером.
- Допустим ли для владельца поиск по UG через /search.php (запрещён в robots.txt) по явному действию пользователя, или ограничиться вставкой URL и Web Share Target из браузера или приложения UG?
- Устраивает ли GPL-2.0-only у ChordSheetJS? Для личного open-source PWA проблем нет; если код закрытый — писать свой парсер ChordsOverWords или взять MIT-альтернативы.
- Нужен ли импорт PDF (Richard G, Doctor Uke) с восстановлением «аккорды над текстом» по координатам pdf.js, или хватит ссылки на PDF с метаданными тональности и числа аккордов?
- Регистрировать ли бесплатное приложение LRCLIB (Lrclib-App-Id, ~180 запросов/мин) и учётку Hooktheory для подборок по прогрессиям?
- Как резолвить spotify_song_id из Chordonomicon в название и артиста без доступа к Spotify API из региона: однократно офлайн из другой сети, или отказаться от датасета в пользу метаданных Richard G и Bytown (число аккордов)?
