# sources-ru

## summary
Открытого датасета русских песен с аккордами и текстами нет. На HF есть только тексты без аккордов (genius-lyrics-russian, без лицензии) и одни аккордовые последовательности без текстов (Chordonomicon, CC BY-NC 4.0). Значит, импорт придётся строить на адаптерах к сайтам. Все проверки шли curl с US-East IP (cf-ray EWR), из Беларуси/РФ доступность не проверена. Из 20+ кандидатов реально пригодны 4–5 сайтов. Лучший по объёму и структуре mychords.net: 246 723 песни и 40 378 исполнителей, мультиязычный, есть JSON-автокомплит, а строка аккордов и строка текста размечены парами в HTML. Самая ценная для укулеле находка — ru.muzland.ru: около 4,9 тыс. песен с отдельными страницами для укулеле, диаграммами GCEA, упрощённой версией (simpl=on) и серверной транспозицией (tone=). akkords.pro — курируемые 1 265 популярных песен, WordPress REST JSON с CORS (отражает Origin), поэтому его можно звать прямо из PWA без прокси; есть схема боя и теги вроде «Топ-100». У amdm.ru самый известный и большой каталог (ID до 219k), но есть минусы: robots запрещает /search всем ботам, ToS прямо запрещает копировать материалы, Cloudflare отдаёт 520 запросам без браузерного User-Agent, песни «Кино» полностью удалены (0 подборов). Поэтому amdm годится только как запасной источник. Остальные исключены: 5lad/ukul.net (поиск только через Google CSE, корень аккорда в span, а суффикс вне его), holychords (только церковный репертуар), pesnipodgitaru (JS-челлендж webguard), gitaristam и pesnibardov (cp1251/нестабильны), bards.ru (почти без аккордов, в HTML внедрён сторонний скрипт), a-pesni.org и bard.ru (недоступны), gl5.ru (домен теперь сайт МФО). Кроме akkords.pro и LRCLIB ни один источник не отдаёт CORS, остальным нужен серверный relay (уже есть на Vercel). Основная инженерная работа — общий нормализатор аккордов (кириллица, H/B, B#, суффиксы вне тегов, табы в тексте) и слияние строки аккордов со строкой текста по колонкам в ChordPro. Для текстов без аккордов LRCLIB хорошо покрывает русский репертуар (Кино, ДДТ, КиШ, ГрОб, Окуджава), отдаёт syncedLyrics и CORS `*`.

## recommendations
- [must] Основной адаптер: mychords.net: Поиск: GET https://mychords.net/ru/ajax/autocomplete?q=<q> обязательно с заголовком X-Requested-With: XMLHttpRequest, иначе 200 с пустым телом. Ответ: {suggestions:[{value:'Артист - Песня',data:{group:'Песни',url:'/ru/kino/1078-kino-gruppa-krovi.html'}}]}. Страница песни: h1.b-title--song ('Артист - Название', делить по ' - '). Текст в div.w-words__text[itemprop=text], пары строк в div.pline > div.c-subline > span.subline×2: первый span — строка аккордов из span.b-accord__symbol, второй — строка текста. Колонка аккорда = смещение в textContent первого subline. Суффикс за </span> (например 'sus4') дописывать к аккорду, стрелки ↓↑ отрезать. div.single-line → {comment} или строка из одних аккордов, span.b-lr-section ('Куплет', 'Припев', 'Вступ') → секции ChordPro, a.b-strumming-pattern и 'Схема боя:' → метаданные боя. Запросы идут через Vercel relay (CORS нет), кэш на 30 дней, не больше 1 запроса в секунду.
- [must] Укулеле-адаптер: ru.muzland.ru: Поиск: GET https://ru.muzland.ru/search.html?query=<q> (HTML). Нужен блок #Ukulele ol.search-result li p.first: первый <a> — исполнитель (songs.html?auth=ID), второй — песня (ukulele.html?auth=ID&song=N). Страница: h1.songname. Текст в <pre>, аккорды — a.chordsty (href /pic/ukulele/Am.gif, это готовые диаграммы GCEA), секции — <B>Припев:</B>. Варианты страницы: &simpl=on (упрощённые аккорды, лучший вариант для новичка) и &tone=Am|Cdm (диез кодируется буквой 'd'). Аккорды проще вынимать как textContent ссылок, затем сливать строки по колонкам. Строки вида 'Am | C | G } 4 раза' → {comment} с аккордами. В Policy: «использовать материалы строго в личных целях», то есть только личная библиотека.
- [must] Курируемый стартовый набор: akkords.pro без прокси: Поиск: GET https://akkords.pro/wp-json/wp/v2/search?search=<q>&per_page=10, ответ [{id,title,url,subtype:'post'}]. Песня: GET /wp-json/wp/v2/posts/<id>?_fields=id,title,content,link,categories,tags. content.rendered содержит p.chords: подписи секций в <b>Куплет 1:</b>, аккорды в <span>F#m</span>, иногда несколько в одном span ('F#m Bm F#m Bm G# A' — делить по пробелам), 'Бой: ↓↑↓↑'. Исполнитель = category (GET /wp-json/wp/v2/categories/15 → 'Кино (Виктор Цой)'). Подборки = tags: 611 «Топ-100 песен на гитаре», 36 «Песни на гитаре с боем», 32 «Популярные», 53 «Русский рок». Сервер отражает Origin (CORS), поэтому PWA на GitHub Pages может ходить напрямую, а relay оставить как запасной путь. Подходит для экрана «первые 20 песен».
- [must] Общий нормализатор аккордов перед ChordPro: 1) Кириллица → латиница: А→A, В→B, С→C, Е→E, Н→H (на pesnipodgitaru встречаются 'С' U+0421 и 'Е7' U+0415). 2) Немецкая нотация: H→B, Hm→Bm, Hb→Bb. Если в песне есть H, одиночное 'B' считать Bb (на holychords и в таблицах 5lad используется H). 3) Энгармонизмы: B#→C (на mychords встречается 'B#m'), E#→F, Cb→B, Fb→E; для укулеле показывать бемоли (A#→Bb). 4) Хвосты вне тегов: 5lad/ukul '<span>A</span>m', mychords '<span>Cm7</span>sus4' — разбирать по тексту строки, а не по тегам. 5) Склеенные аккорды 'GF' (gitaristam) — токенизировать регэкспом. 6) '(E7)' — альтернативный аккорд, хранить как [E7] с пометкой. 7) Строки табулатуры /^[eEBGDAa]\|[-0-9hpb\/|]+/ (есть на amdm) → {start_of_tab}. 8) 'x2', '}x2', '4 раза', стрелки ↓↑ → {comment}. 9) Капо/«удобная тональность» из комментариев → мета. Слияние: строка считается строкой аккордов, если ≥80% токенов матчат регэксп аккорда; аккорд вставляется в следующую строку текста по колонке (табы расширять до 8 пробелов, отступы не обрезать до слияния).
- [must] Relay на Vercel с allowlist хостов, кэшем и health-check: Без CORS отдают amdm.ru, mychords.net, top.5lad.net, ukul.net и ru.muzland.ru, а holychords отдаёт ACAO только для http://localhost:3000. Нужен прокси на Vercel: allowlist доменов, TTL-кэш (Vercel KV или Neon), ответ уже в виде ChordPro, загрузка только по действию пользователя, без фонового краулинга. Регион функции лучше выбрать европейский (например fra1). Отсюда (US) amdm, mychords, 5lad и muzland отвечали 200, а a-pesni.org и gitaristam таймаутили, то есть из датацентров они могут не работать. Нужен ежедневный health-check каждого адаптера на эталонной песне: разметка меняется (amdm перешёл с <b> на div.podbor__chord).
- [should] LRCLIB как источник текстов без аккордов: GET https://lrclib.net/api/search?q=<артист песня> или /api/get?artist_name=&track_name=[&duration=] → plainLyrics/syncedLyrics. CORS '*', ключ не нужен, нужен осмысленный User-Agent. Русский репертуар покрыт: «Группа крови» (Кино) — 20 результатов, есть synced; ДДТ, Король и Шут, ГрОб, Окуджава находятся. Применения: (а) найдена только последовательность аккордов — подставить текст; (б) караоке-режим со scroll по syncedLyrics; (в) сверка названия и артиста перед поиском аккордов. lyrics.ovh для ДДТ вернул 404, не использовать.
- [could] amdm.ru — только как опциональный запасной адаптер: Поиск: GET https://amdm.ru/search/?q=<q> → table.items td.artist_name > a.artist (первая ссылка — исполнитель, вторая — песня /akkordi/<artist>/<id>/<slug>/). Песня: h1 span[itemprop=byArtist], h1 span[itemprop=name]. Текст в pre[itemprop=chordsBlock].podbor__text, аккорды — div.podbor__chord[data-chord] (div внутри pre), секции — div.podbor__keyword ('[Куплет]:'). Против: robots.txt для '*' запрещает /search и /api/; ToS (/rules/rid/): «не вправе копировать и распространять Материалы»; Cloudflare отвечает 520 на запросы без браузерного UA (это сигнал, что автоматические клиенты нежелательны); каталог «Кино» удалён (0 подборов). Включать только по явному запросу владельца и только для личного использования.
- [should] Мультиисточник и выбор версии: Одна и та же песня в разных источниках записана в разных тональностях: «Группа крови» на akkords.pro в F#m, на mychords в B#m (=Cm), «Что такое осень» на amdm в Am, а на mychords в Fm. Поэтому после импорта нужно транспонировать в «укулельную» тональность: перебрать 12 сдвигов и выбрать минимальный суммарный вес аккордов (C, Am, F, G, Dm, Em, A7 — лёгкие; E, Bb, B, F#m, C#m — сложные). Показывать 2–3 версии из разных источников, у каждой хранить source_url. Это закрывает и снятия по требованию правообладателей.
- [avoid] Не использовать pesnipodgitaru, gl5, bards.ru, a-pesni, bard.ru и датасеты как источник аккордов: pesnipodgitaru.ru: JS-челлендж webguard (cookie BPC7, slowAES), обходить его нельзя; к тому же страница — статья-разбор с кусками <pre> внутри текста, а не песенник. gl5.ru: домен теперь занимает сайт о микрофинансах. bards.ru: работает только по HTTP, IIS 6, почти без аккордов, в <title> внедрён <script src=//abunew.com/cookie>. a-pesni.org: TCP открыт, HTTP не отвечает. bard.ru: не резолвится DNS. HF/Kaggle: русских аккордов вместе с текстами нет. Из bards.ru и других старых сайтов никогда не вставлять сырой HTML.
- [could] Ultimate Guitar для русских песен — вне этого измерения: На UG много русских песен с кириллическими метаданными: поиск «группа крови» дал 57 результатов, Chords с рейтингом 4.8–4.9, данные в div.js-store[data-content] JSON. ToS запрещает скрейпинг, Cloudflare. Решать вместе с измерением англоязычных источников; как основной источник для русских песен не закладывать.

## risks
- Юридический риск: аккорды пользовательские, тексты под авторским правом. ToS amdm запрещает копирование, muzland разрешает только личное использование, 5lad ссылается на ст. 1274 ГК РФ (учебные цели). Импорт допустим только в личную библиотеку владельца, без публичного шаринга. Хранить source_url и дату.
- Снятия по требованию правообладателей: на amdm у «Кино» 0 подборов, на mychords 405 песен, на akkords.pro 56. Каталоги меняются без предупреждения, поэтому нужен мультиисточник.
- Дрейф разметки: amdm перешёл с <b> на div.podbor__chord, сломав старые парсеры. Без ежедневного health-check адаптеры молча начнут отдавать пустые песни.
- Тихие отказы: autocomplete mychords без X-Requested-With отдаёт 200 с пустым телом; pesnipodgitaru нерегулярно отдаёт 200 со страницей JS-челленджа вместо контента. Проверять content-type и маркеры ('Please wait', 'webguard').
- Антибот: Cloudflare на amdm отвечает 520 на не-браузерные UA. Подмена UA в обход такой фильтрации этически и юридически сомнительна; источник лучше считать опциональным. Webguard на pesnipodgitaru не обходить.
- Геодоступность: все проверки шли с US-East IP. a-pesni.org и gitaristam.ru таймаутили (возможно, это геоблок или защита от датацентров), так что с relay на Vercel они могут не работать, а с телефона в BY — работать. Обратное тоже возможно: Cloudflare может давать челлендж IP-адресам Vercel/AWS.
- Кодировки: gitaristam и bards.ru отдают windows-1251. Декодировать по charset из заголовка или meta, иначе получится мусор.
- Безопасность: в <title> bards.ru внедрён внешний скрипт (//abunew.com/cookie). Импортированный HTML никогда не рендерить как HTML: только парсинг в ChordPro или текст с экранированием.
- Качество данных: одна песня встречается в разных тональностях (F#m, B#m=Cm, Am, Fm) и с ошибками (B#, кириллические буквы, H/B). Без нормализатора и авто-транспонирования новичок получит неудобные для укулеле аккорды (E, B, F#m, C#m).
- Гитарные подборы не учитывают укулеле: табы (E|---) и баррэ-контекст при переносе бессмысленны. Табы нужно отделять от аккордов, а аппликатуры строить своей библиотекой для GCEA и опционально low-G/DGBE (у muzland только картинки GCEA).
